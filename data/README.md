# ElectionWatch — Static Data Artifacts

Pre-built static data for the May 4, 2026 counting day (5 in-cycle states:
Assam 126 ACs, Kerala 140 ACs, Tamil Nadu 234 ACs, West Bengal 294 ACs,
Puducherry 30 ACs = **824 total ACs**).

---

## Directory Layout

```
data/
├── topojson/               # TopoJSON boundary shards (5 states)
├── svg/                    # Overview SVG (5-state silhouette)
├── historical/             # Historical election JSONs
├── dist/                   # Content-hashed production artifacts
├── raw/                    # Raw shapefile sources (gitignored)
├── alliance_map_2026.json  # Party → alliance hand-curated mapping
├── search_index.json       # 824-row constituency search index
├── build.ts                # Build pipeline (raw → dist/)
├── build_data.py           # Historical / metadata data builder
└── build_search_index.py   # Search index generator
```

## Artifacts

### TopoJSON Shards (`topojson/`)

Five per-state TopoJSON files, one per in-cycle state.

| File | State | ACs | Raw | Gz |
|------|-------|-----|-----|----|
| `india_constituencies_S03.topojson` | Assam | 133* | 74 KB | 22 KB |
| `india_constituencies_S11.topojson` | Kerala | 141* | 70 KB | 21 KB |
| `india_constituencies_S22.topojson` | Tamil Nadu | 234 | 150 KB | 46 KB |
| `india_constituencies_S25.topojson` | West Bengal | 294 | 164 KB | 49 KB |
| `india_constituencies_S26.topojson` | Puducherry | 30 | 11 KB | 3 KB |

All shards are **≤300 KB gz** (budget). Budget headroom is large — even
West Bengal at full source resolution is 49 KB gz.

**Feature properties:** `{ac_no: int, name: str, state_code: str, ls_parent: str}`

**Source:** DataMeet community archive (CC-BY 2.5 India), shapefile
`India_AC.shp` from `github.com/datameet/maps`. Processed with
`mapshaper 0.7.7` at full source resolution (the DataMeet source is
already reasonably simplified — no further simplification applied).

> ⚠️ **Assam note (L1 decision, 2026-05-01):** The DataMeet shapefile
> carries **pre-2023-delimitation** Assam boundaries (133 ACs). Post-2023
> delimitation reduced the count to 126 ACs with redrawn constituency
> boundaries. The file shipped here uses the pre-delimitation geometry as a
> **visual approximation only**. For production accuracy, replace
> `topojson/india_constituencies_S03.topojson` with the post-delimitation
> shapefile from NESDR (nesdr.gov.in, dataset "Assam Assembly Constituency
> Boundary Map", resource id a907b71b-3094-4a98-bed0-d18ca584bfc2) and
> re-run `build.ts`. The frontend join key is `ac_no`, which already
> follows 2023 numbering in `historical_assembly_2021_assam.json`.

> ⚠️ **Kerala note:** DataMeet carries 141 Kerala ACs (one stale entry).
> Kerala has 140 official ACs. The extra feature is a minor data artifact
> and does not affect map rendering.

### Overview SVG (`svg/india_overview.svg`)

5-state state-boundary silhouette, ~22 KB raw. Each state is a `<path>`
element with `id` matching the ECI code (`S03`, `S11`, `S22`, `S25`, `S26`).
Used by `<OverviewSvgChoropleth>` for the landing-page map fill.

Generated by dissolving all ACs per state via mapshaper at 5% simplification.

### Historical LS Data (`historical/`)

| File | Rows | Content |
|------|------|---------|
| `historical_2024_ls.json` | 543 | 2024 General Election — per LS seat winner + vote-share |
| `historical_2019_ls.json` | 543 | 2019 General Election — same schema |
| `historical_assembly_2021_assam.json` | 126 | 2021 Assam assembly — per AC |
| `historical_assembly_2021_westbengal.json` | 294 | 2021 West Bengal assembly — per AC |
| `historical_assembly_2021_tamilnadu.json` | 234 | 2021 Tamil Nadu assembly — per AC |
| `historical_assembly_2021_kerala.json` | 140 | 2021 Kerala assembly — per AC |
| `historical_assembly_2021_puducherry.json` | 30 | 2021 Puducherry assembly — per AC |

**LS schema:**
```json
{"pc_id":"AS01","pc_name":"Dhubri","state_code":"S03","winner_party":"AIUDF",
 "vote_share":{"AIUDF":44.3,"INC":25.8,"BJP":13.2,"others":16.7}}
```

**Assembly schema:**
```json
{"ac_no":1,"ac_name":"Gossaigaon","winner_party":"BJP",
 "vote_share":{"BJP":46,"INC":30,"BPF":14,"others":10}}
```

**Sources:** ECI Statistical Reports (2019, 2024 General Elections; 2021
assembly cycles). State-level aggregate outcomes are authoritative;
constituency-level vote-share values are derived from known state
distributions — treat as reference approximations for historical overlay.

### Alliance Map (`alliance_map_2026.json`)

Hand-curated party → alliance mapping for 2026 in-cycle states.

Alliance values: `NDA`, `INDIA`, `LDF` (Kerala only), `Others`.

**Key L1 decisions documented in `_meta._l1_decisions`:**
- **AIADMK → Others**: split from BJP-NDA in June 2023; contested 2024 LS independently. TN 2026 ECI filings show AIADMK as unaffiliated.
- **Kerala LDF → separate `LDF`**: not formally in INDIA alliance; frontend should render as distinct 4th color in Kerala state view.
- **PMK → NDA**: returned to NDA fold per TN 2026 ECI declaration.
- **AIUDF → INDIA**: formal INC-led opposition alliance for Assam 2026.

## Build Pipeline

```bash
cd web/
npx ts-node -O '{"module":"commonjs"}' ../data/build.ts
```

Outputs to `data/dist/` with content-hash filenames.
`data/dist/manifest.json` maps logical → hashed filenames for frontend use.

**To rebuild after updating source files:**
1. Edit source files in `data/topojson/`, `data/historical/`, etc.
2. Re-run `build.ts`.
3. Commit updated `data/dist/` files.

---

## Updating for Future Election Cycles

- **New assembly results**: update state arrays in `build_data.py`, re-run, rebuild.
- **Post-delimitation Assam**: download NESDR post-2023 shapefile, replace `topojson/india_constituencies_S03.topojson`, rebuild.
- **Alliance changes**: edit `alliance_map_2026.json` — frontend re-colors immediately.
